# Iris Flower Classification 🌸

This project is a Machine Learning model that classifies Iris flowers into three species:
- Setosa
- Versicolor
- Virginica

## 📊 Technologies Used
- Python
- Pandas
- Scikit-learn

## 🚀 Steps Performed
1. Loaded dataset using sklearn
2. Created DataFrame
3. Split data into training & testing
4. Trained model using RandomForestClassifier
5. Evaluated accuracy

## 📈 Output
Model achieved high accuracy on test data.

## 💡 Learning
- Basic ML classification
- Train-test split
- Model evaluation
